# Changelog

All notable changes to this module are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/), and this
module follows [Semantic Versioning](https://semver.org/).

## v1.2.0

### Added

* The SRD 5.1 equipment as content: `content.Weapons`, `content.Armor`
  (armour and the shield), `content.Gear` (ammunition and selected
  adventuring gear), `content.StandardItems` (their union), and
  `content.RegisterStandardItems` (loads that union into a
  `content.Registry[content.Item]`). Every value is pinned to the SRD 5.1
  text by fixtures under `content/testdata/`, generated by
  `content/testdata/fetch-srd-2014.py`.
* `core.Coins`, an integer copper-piece amount with `core.Cp`, `core.Sp`,
  and `core.Gp` constructors for the SRD's coin denominations.
* `dice.MustParse`, a `dice.Parse` wrapper that panics on a malformed
  expression, for callers building `dice.Expr` values from constants.

### Changed

* **Breaking:** `core.Weight` changed its underlying type from `int` to
  `float64`, so it can represent the SRD's fractional pounds (for example a
  dart at 1/4 lb.). No known consumer depended on the integer
  representation, but any caller doing integer arithmetic or `%d`
  formatting on a `core.Weight` value will fail to build or format
  incorrectly and needs updating.
